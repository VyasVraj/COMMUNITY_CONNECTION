# Supabase Seed Data

Seed scripts live in this directory.

## Purpose

- Local development seed data
- Testing fixtures
- Demo community data for development/staging

## Rules

- Seed data is for development/staging ONLY.
- NEVER run seed scripts against production.
- Seed data must not contain real personal information.
- Use realistic-looking but entirely fictional data.

## Phase 0

No seed data is created in Phase 0.
Seed data will be created alongside schema in Phase 1+.
